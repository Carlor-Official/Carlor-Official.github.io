快速开始 ​

1. 下载正式包 ​

打开 GitHub Releases，按系统和 CPU 架构下载对应压缩包。当前正式版是 v2.3.8。

下载后建议使用同一发布页中的 SHA256SUMS.txt 校验文件完整性。

2. 解压并启动 ​

Windows：

powershell
.\mengka-nt.exe

Linux：

bash
chmod +x ./mengka-nt
./mengka-nt

首次启动时，终端会显示 Web 安装地址。打开该地址，阅读使用协议，并按向导设置监听端口以及本机管理员账号、密码。管理员凭据只保存在当前框架的本地数据库中，不依赖官网用户体系。

从旧版官网管理员迁移

如果页面检测到旧版官网管理员，请先在服务器设置 MENGKA_ALLOW_LOCAL_ADMIN_MIGRATION=1 并重启，再创建本地管理员。确认新账号可以登录后，移除该环境变量并再次重启。迁移只替换管理员身份，不会删除 QQ 账号、插件、节点或运行数据。

3. 准备账号环境 ​

进入 WebUI 后按下面顺序操作：

  1. 在“节点”中检查或添加连接节点；
  2. 在“指纹”中创建账号使用的设备指纹；
  3. 在“账号”中添加 QQ，并选择协议、指纹和节点；
  4. 发起登录，按页面提示完成滑块、短信或其他安全验证；
  5. 登录成功后检查账号在线状态和运行日志。

4. 接入插件 ​

在“插件”中创建服务，选择正向或反向 WebSocket，妥善保存服务令牌。不要把令牌写入公开源码、前端代码或 URL。
