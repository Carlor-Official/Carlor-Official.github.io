# 外部插件说明示例：B站综合插件

这是一篇外部插件发布说明示例。实际发布时应使用真实界面截图、明确的版本号和可验证的安装包。

## 发布信息

| 项目 | 示例内容 |
| --- | --- |
| 插件名称 | B站综合插件 |
| 版本 | `1.4.6` |
| Windows | `BilibiliSuite-1.4.6-windows-x86_64.zip` |
| Linux AMD64 | `BilibiliSuite-1.4.6-linux-x86_64.tar.gz` |
| 接入模式 | 正向 WebSocket + 反向 WebSocket |
| 默认端口 | `3050` |
| 网页后台 | 支持 |

## 安装和对接

1. 从插件自己的正式发布页下载与系统架构匹配的成品包。
2. 核对发布页提供的 SHA-256。
3. 打开萌卡 NT 的「插件 → 插件导入」，填写插件名称、插件 ID 和版本。
4. 上传安装包，等待卡片显示运行状态。
5. 上传同一插件 ID 的更高版本时，框架会在原卡片内更新并保留业务数据。
6. 如果插件选择外部部署，再到「插件对接」添加正向或反向 WS 服务。

## 反馈

插件主页应提供明确的问题反馈入口，并说明需要携带的版本、系统、架构和脱敏日志。
