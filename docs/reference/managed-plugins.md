# 插件导入

萌卡 NT 使用本地插件库替代官网插件市场。框架不会读取官网插件清单，也不会从远程地址下载插件。管理员取得成品包后，在「插件 → 插件导入」手动上传并管理。

## 支持的安装包

- ZIP；
- TAR.GZ 或 TGZ；
- 单个文件最大 512 MiB；
- 当前框架运行平台对应的可执行程序或 Linux 启动脚本。

框架会拒绝路径穿越、符号链接、特殊文件和超过解压限制的安装包。上传文件会记录 SHA-256，并保存在框架预留的 `data/managed-plugins/imports` 目录中。实际目录会显示在插件导入页顶部。

## 第一次导入

1. 点击「上传插件」。
2. 选择成品包。
3. 填写插件名称、稳定的插件 ID 和三段式版本号，例如 `1.0.0`。
4. 如果插件提供 Web 管理端，勾选对应选项并先完成访问入口配置。
5. 点击「导入并安装」。

安装任务会安全解压程序、识别启动入口、创建独立数据目录、生成正向 WebSocket 服务并启动插件。页面关闭不会取消后台任务。

## 上传新版本

再次上传相同插件 ID、版本更高的安装包时，框架在原卡片中更新，不会新增第二张卡片。新包通过校验后才会停止旧进程并切换；启动失败时恢复旧程序。业务数据目录保持不变。

同版本覆盖和降级默认拒绝。如需重装当前版本，先卸载程序，再重新上传安装包。卸载只删除程序目录，业务数据继续保留。

## 卡片管理

每个已导入插件对应一张卡片。卡片保留原托管能力：

- 查看安装和运行状态；
- 启动、停止和卸载；
- 查看脱敏运行日志；
- 修改业务数据目录；
- 打开已配置的 Web 管理端；
- 跳转到插件对接页面查看自动生成的服务。

历史版本从官网市场安装的记录不会被升级删除，但新的安装和更新只接受本地上传包。
