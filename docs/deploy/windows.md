# Windows 部署

## 启动

将正式 ZIP 解压到独立目录，在 PowerShell 中运行：

```powershell
.\mengka-nt.exe
```

需要临时查看协议调试信息时：

```powershell
.\mengka-nt.exe -debug
```

不建议长期启用调试日志；日志可能包含命令与错误上下文。

## 升级

1. 停止萌卡 NT 进程；
2. 完整备份原目录中的 `data`；
3. 解压新版本到新的临时目录；
4. 按版本说明迁移程序文件，保留原运行数据；
5. 启动并验证 WebUI、账号登录、插件连接与消息收发；
6. 验证完成后再清理旧备份。

::: danger 不要直接覆盖数据
不要用新包中的空目录覆盖旧版本的 `data`，也不要把配置、数据库或登录缓存上传到 GitHub。
:::
