# 仓库与资源

| 资源 | 用途 |
| --- | --- |
| [Mengka-NT](https://github.com/Carlor-Official/Mengka-NT) | 正式发布、SDK 文档与版本说明 |
| [最新 Release](https://github.com/Carlor-Official/Mengka-NT/releases/latest) | 下载 Windows / Linux 外发包 |
| [Issues](https://github.com/Carlor-Official/Mengka-NT/issues) | Bug 与建议反馈 |
| [Node.js SDK](https://github.com/Carlor-Official/Mengka-NT/tree/master/sdk/nodejs) | 插件连接、action 调用与事件处理 |
| [WebUI SDK](https://github.com/Carlor-Official/Mengka-NT/tree/master/sdk/plugin-web) | 将插件管理页安全嵌入框架 WebUI |

::: tip 发布边界
源码仓库、测试包、正式签名 Release 和生产部署是不同交付物。对外使用时以 GitHub Releases 中的正式包和校验文件为准。
:::
