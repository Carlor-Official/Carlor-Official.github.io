# 升级检查单

## v2.5.15 群语音上传修复

v2.5.15 修复 Android 9.1.70 上传通道初始化时错误强制索取签名的问题。调用参数、返回语音段和 MP3 输入要求不变；上传失败会指出是在申请语音凭据还是获取上传通道阶段。

## v2.5.14 补挂执行修复

单项异常、超时或尚未完成时继续后续补挂任务，保留该项提示，不自动重试。免费小说恢复三分钟阅读心跳与结算；电脑在线只展示实际在线时长。批量 API 最终报错不表示其他任务未执行，重试前请刷新核对。整体请求取消或总预算到期仍会停止。

## v2.5.13 等级任务恢复

更新完整外发包后刷新任务列表。QQ 返回的 `is_vip_task` 不能当作付费标记；管理面板保留非购买任务，并恢复安卓电脑在线、直接擂台和会员签到入口。电脑在线显示同号 Linux 会话时长，手机连续在线只展示待完成或已完成。会员任务需要满足对应账号权益和活动条件，成长值不计入 QQ 加速天数；元宝执行器尚未适配 9.1.70，仍保留展示并标明不可补挂。

原有任务计划及执行记录保留，失败不会自动重放。以下 v2.5.9 内容记录该版本的迁移调整；其中电脑在线、擂台和会员签到的停用说明已被本节更新。

## v2.5.9 重要调整

升级前停止框架，完整备份 `data` 与插件数据。使用与系统和架构匹配的完整外发包更新程序、前端和协议目录，保留现有账号与配置数据。

- Android 仅保留 QQ 9.1.70（Phone / Pad），Linux 保留 3.2.32。旧 9.2.70 账号需重新选择支持的协议；不要手工重排协议 ID。
- Linux 提供免扫、扫码、账号密码三种登录方式。原先填写占位密码的账号，需要先编辑为真实密码，再使用账号密码登录。
- 等级任务使用新版执行器。旧擂台、元宝、电脑在线及独立会员签到执行器已停用；历史数据与计划保留，请按新面板检查自动计划。
- 语音和视频改用原生处理，框架不再提供 Docker/FFmpeg 管理。语音上传使用 MP3；下载转 WAV 支持 MP3/SILK，MP3 输出只保持已有 MP3，其他格式不再自动转码。
- `get_skey`、`get_clientkey` 共用原 action，通过 `client_type` 选择账号协议。Node.js SDK 可传第二参数 `android` / `linux`，返回字段不变。
- 请同步更新配套 SDK。省略协议的既有快捷调用仍默认 Android，同一 QQ 的不同协议会话不会互相替代。

如需回滚，先停止新程序，再恢复升级前的程序与数据备份，不要让两个版本同时写入同一数据目录。

## 升级前

- 阅读目标版本 Release 说明与破坏性变更；
- 停止框架和依赖它的插件；
- 完整备份 `data`、配置文件和必要的插件数据；
- 下载与操作系统、CPU 架构匹配的正式包；
- 使用 `SHA256SUMS.txt` 校验下载文件。

## 升级后

- 框架进程正常启动，版本号正确；
- WebUI、管理员登录与 HTTPS 正常；
- 每个账号的协议、指纹、节点和在线状态正确；
- 正向/反向插件均能认证和接收事件；
- 核心 action、消息收发和管理操作通过；
- 日志中没有持续的数据库迁移、权限或连接错误。

## 回滚

如果新版本无法通过验证，停止新进程，恢复升级前程序和数据备份，再检查对应版本的日志。不要让两个版本同时写入同一份数据库或 `data` 目录。
